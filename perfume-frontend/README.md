# Aura Perfumé — Frontend

React + TypeScript + Vite + Tailwind CSS ile yazılmış mağaza arayüzü. Tüm veriler `http://localhost:3000/api` adresindeki backend'den gelir.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # yayına hazır sürüm (dist/)
npm run lint
```

Kurulum, sunum akışı, test kartı ve proje yapısı için üst klasördeki [README.md](../README.md) dosyasına bakın.
